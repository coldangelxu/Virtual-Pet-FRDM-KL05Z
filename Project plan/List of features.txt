Basic Features:

2S Power System: Independent power supply from two 18650 cells (7.4V), stepped down to a stable 5V via an LM2596 regulator.

Movement (4 Servos): Control of four SG90 servomotors using a hardware PWM module (TPM0). Basic postures: standing, sitting, and resting.

Face Interface (OLED): Displaying basic eye bitmaps (open, closed) retrieved directly from Flash memory via I2C.

Sound (Passive Buzzer): Generating simple tones using a hardware timer (TPM1).

Petting and Shaking: Utilizing the built-in accelerometer (MMA8451Q) and a touch slider to change the mood (Anger/Joy).

Extended Features:

PC Communication: Sending text frames containing the pet's current status to a computer via UART.

Virtual Feeding and Play (RFID): Reading RFID tags via the SPI bus (distinguishing between "food," "toy," and "water").

Advanced Movement: Enabling forward and backward walking.

Melody Player: Asynchronous (non-blocking) playback of note sequences (frequencies and durations) stored in Flash memory.

Environmental Response:

Cold: Reading from an LM35 sensor (via ADC) to trigger a shivering animation.

Tapping/Knocking: Detecting double-taps on a surface (using an SW-420 sensor) to wake up the robot.

LabVIEW Dashboard: An interactive front panel featuring graphs of vital signs, a battery level indicator, and remote control buttons.
